Aide

Le principe

  1. Choisissez un exercice dans la liste, en haut.
  2. Lisez l'énoncé, écrivez votre code.
  3. ▶ Exécuter (Ctrl+Entrée) lance votre code : ce qu'il affiche apparaît dans la console.
  4. ✓ Tester lance les tests de l'exercice : chaque ❌ explique ce qui ne va pas.
  5. Coincé ? Les indices 💡 sous l'énoncé, puis un coup de pouce sur le Discord ou auprès de Nami. La correction, dans le support de cours, en dernier recours.

Lire et écrire

  • console.log(valeur) affiche une valeur dans la console : c'est l'ÉCRIRE du pseudo-code.
  • lire("nom") lit la valeur appelée nom dans le panneau Entrées : c'est le LIRE du pseudo-code. Cette fonction n'existe que dans le playground.
  • Dans le panneau Entrées, une ligne par entrée : age = 17. Les nombres à virgule s'écrivent avec un point : 12.5. Un texte qui ressemble à un nombre s'écrit entre guillemets : code = "75001".
  • Plusieurs valeurs séparées par des virgules, notes = 12, 15, 9, se lisent l'une après l'autre : le premier lire("notes") donne 12, le suivant 15, puis 9.

Bon à savoir

  • Votre code est sauvegardé automatiquement dans ce navigateur, exercice par exercice. Changer de navigateur ou vider ses données efface la sauvegarde.
  • ↺ remet le code de départ de l'exercice.
  • Le code tourne en mode strict : toute variable doit être déclarée avec let ou const.
  • Un programme qui ne s'arrête pas (boucle infinie) est interrompu au bout de 3 secondes. En mode page, si l'onglet se fige, fermez-le et rouvrez le playground : votre code est sauvegardé.
  • Ctrl+/ commente ou décommente les lignes sélectionnées.
  • 🌓 change le thème : automatique (celui de votre système), sombre ou clair.
  • 📓 Journal : chaque soir, téléchargez votre journal et déposez-le sur Moodle. Vous y cochez aussi votre auto-évaluation « Je sais… ».

📓 Mon journal

Chaque soir, téléchargez votre journal et déposez-le sur Moodle. Il contient tout votre travail depuis le début : vos essais, vos résultats aux tests, vos indices, vos réponses, votre auto-évaluation, avec leurs dates. Une signature permet de vérifier qu'il n'a pas été modifié après coup.
